# 6. 레이아웃

## 콘텐츠 폭 (PC)

| 이름 | 폭 | 쓰는 화면 | GlobalNav width |
|---|---|---|---|
| default | 1180(가운데) | 목록 · 상세 · 입력 폼 · 일반 대시보드 | default |
| wide | 1440(가운데) | 차트가 많은 대시보드 · 넓은 표 · 리포트 | wide |
| full | 화면 전체, 좌우 48 | 지도 화면 | fill |

- 기본은 default. 표 · 차트를 4칸 이상 나란히 둬야 하면 wide, 지도는 full.
- 화면이 콘텐츠 폭보다 좁으면 좌우 최소 여백 48을 지키며 줄어든다.

## 페이지 간격

| 항목 | PC (1024~) | 모바일 (~767) |
|---|---|---|
| 좌우 여백 | `spacing-12` 48 | `spacing-5` 20 |
| 페이지 상단(GNB 아래 ~ 제목) | `spacing-10` 40 | `spacing-6` 24 |
| 페이지 제목 ~ 첫 섹션 | `spacing-8` 32 | `spacing-6` 24 |
| 섹션 사이 | `spacing-12` 48 | `spacing-8` 32 |
| 섹션 제목 ~ 내용 | `spacing-4` 16 | `spacing-3` 12 |
| 카드 사이 | `spacing-4` 16 | `spacing-3` 12 |
| 페이지 하단 | `spacing-12` 48 | |
| 페이지 제목 · 섹션 제목 | `text-2xl-bold` · `text-lg-semibold` | `text-xl-bold` · `text-base-semibold` |

- 태블릿(768~1023)은 모바일 레이아웃 + 좌우 32.

## 카드 그리드 · 크기 (PC)

4칸 그리드(카드 사이 16). 카드는 가로 줄 안에 넣고 **칸을 채운다(fill)**.

| 칸 | 폭(default) | 쓰는 곳 |
|---|---|---|
| 1/4 | 283 | 수치 요약(StatisticCard) |
| 1/3 | 382 | 짧은 텍스트 요약(Text Card), 작은 차트 |
| 1/2 | 582 | 차트 · 짧은 목록 |
| 전체 | 1180 | 표 · 긴 목록 · 큰 차트 |

- wide에서 1칸 348.
- 최소 폭: Statistic · Text Card lg 240 · sm 150, Card Layout 320. 칸이 최소 폭보다 좁으면 칸 수를 줄여 다음 줄로.
- 카드 Size 이름 = 모서리 단계: PC **lg**(모서리 · 여백 24), 모바일 · 좁은 칸 **sm**(16), 큰 판 xl(32).
- 좁은 칸의 StatisticCard는 숫자 · 증감을 세로 배치.
- 높이는 내용에 맞추고 같은 줄 카드는 높이를 맞춘다. 차트 카드 최소 높이: 작은 차트 240, 큰 차트 320. 길면 페이지네이션 · 더보기.
- 카드 고르기: 숫자 하나 + 증감 → StatisticCard / 본문 3줄 이하 → Text Card / 4줄 이상 · 목록 · 차트 · 표 → Card(+ Contents Header).
- 넘침: Statistic 설명 최대 2줄, Text Card 본문 최대 3줄(말줄임). 숫자는 줄바꿈하지 않는다.

## 모바일 (~767)

- 카드 Size=sm, 기본 1열. StatisticCard만 2열(칸 150 이상, 360 미만 화면은 1열).
- 입력창 **2xl(16px)** — iOS에서 16px 미만이면 화면이 확대된다.
- 버튼 · 입력창 기본 xl(40), 하단 고정 주요 버튼 2xl(48) + 폭 꽉 채움.
- 헤더는 GNB 대신 Mobile NavLogo · Title bar.
- 모달: 확인형은 폭 = 화면 − 32(최대 400), 내용이 많으면 Bottom Sheet 또는 전체 화면. Report Modal 모바일형은 폭 fill(최소 320 · 최대 560), 높이는 내용에 맞추고 최대 640(화면이 낮으면 화면 − 40), 내용 영역만 스크롤. 모바일 모달 · Bottom Sheet는 모서리 `surface-md` 20 · 여백 20.
- 표는 Minimal Table · 가로 스크롤 · 카드 목록.
- hover가 없다 — hover 모양은 누르는 동안(pressed) 표시로 쓴다.

## 마지막 줄 구분선

- 목록 · 격자 · 표 · 메뉴처럼 줄마다 아래 구분선이 있는 묶음은 **마지막 줄의 아래 구분선을 항상 지운다** — 판 테두리나 다음 영역의 위 구분선과 겹쳐 두 줄로 보이지 않게.
