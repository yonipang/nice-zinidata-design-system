# 9. 표

## 어떤 표를 쓰나

| 화면 | 표 | 헤더 칸 | 본문 칸 | 구분선 |
|---|---|---|---|---|
| PC | **Table** | Header Text | Table Text(+ 칸 안 컨트롤) | 본문 줄 아래 1px `divider-neutral-subtle` |
| 모바일 | **MinimalTable** | Header Top(· Header Left) | Minimal Cell · Metric · Delta | 없음 |

- 헤더 컴포넌트는 **헤더 줄에만**, 본문 컴포넌트는 본문에만.
- 차트 아래 표도 같은 기준(PC Table · 모바일 Minimal).

## 행 · 배경

- 행 높이 **36px**(헤더 · 본문 모두). 칸 높이를 늘려 행을 키우지 않는다.
- **헤더 셀에는 배경이 없다.** 표를 만들 때 **헤더 줄 프레임**에 배경을 정한다: 흰 헤더 `table-header-main`, 회색 헤더 `table-header-subtle`. **MinimalTable 헤더는 항상 흰색.** 한 화면의 표는 같은 헤더 배경. (고정 열 Fixed=right · bottom 셀만 스크롤 내용을 가리려고 배경을 가진다)
- 본문 줄 `table-row-main`, 줄무늬 `table-row-subtle`, 선택 줄 `table-row-selected`(강조 `-primary` · 오류 `-negative`). **표 배경에 surface 토큰을 직접 쓰지 않는다.**

## 정렬 · 칸

- **숫자 데이터와 그 열 헤더는 오른쪽 정렬**(%, %p, 원, 건 등 단위 포함). 글자는 왼쪽. 여러 열을 묶는 상위 헤더는 가운데.
- 증감이 없는 숫자(순번 · 금액 · 개수)도 일반 글자 칸(Table Text `Type=text`). `number`는 숫자 아래 증감이 붙는 칸.
- 칸 안 막대: 값 + 이름 세로 basic, 양 끝 비율(개인 14% · 법인 86%) composition.
- **줄마다 반복되는 버튼은 solid 금지** → Neutral base sm(Table Button 기본값).

## 차트 아래 표

- 본문 첫 칸 = 차트 카테고리(**같은 순서**). 줄바꿈 라벨은 한 줄로.
- 헤더 시리즈 칸 = 시리즈 이름 + **차트와 같은 색 네모**. 본문 값 칸에는 네모를 넣지 않는다.
- 시리즈가 아닌 열(예: 점포 표본수)과 도넛 · 파이 표에는 네모 없음.
- PC와 모바일 차트는 같은 데이터. 모바일 축 라벨이 듬성듬성해도 표는 모든 행을 보여준다.

## 교차표

차트 카테고리가 **열**인 표(예: 연령대 × 성별)는 위 규칙을 그대로 쓰지 않는다 — 상위 헤더(연령대, 가운데) + 하위 헤더(여성 · 남성, 숫자 열이라 오른쪽) 2줄, 본문 행은 기간(25.12 · 25.11 · 증감). 하위 헤더 칸 폭 = 본문 값 칸 폭.
