# 11. 아이콘 · 로고

## 아이콘

- 회사 **Icon Set**(line 스타일, 24px 그리드, 이름은 Remix Icon 체계)을 쓴다. Icons 자산 그룹과 컴포넌트 번들의 아이콘은 원본 벡터를 그대로 옮긴 것이다.
- 색은 부모의 `icon-*` 토큰(`currentColor`), 인스턴스에서 덮어쓰지 않는다. 아이콘에 `fill-*`을 쓰지 않는다.
- 크기: 버튼 sm 14 · md/lg 16 · xl 18 · 2xl 20, 입력창 md 16 · xl/2xl 20, 도움말 16.
- 자산에 없는 아이콘은 비슷하게 그리지 않는다 — 받기 전까지 글자로 대신한다. 이모지는 쓰지 않는다.

## 로고

- Logos 그룹의 NICE ZINIDATA 로고(BG=White · Black · Transparent)를 그대로 쓴다. 토큰 연결 대상이 아니며 색을 바꾸거나 다시 그리지 않는다.
