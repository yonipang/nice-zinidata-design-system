# 10. 차트

- 막대 · 선 · 도넛 기본형(**BarChart · LineChart · DonutChart**), 피그마는 📊 charts v1.0.
- 시리즈 색은 **Primitive를 직접 쓰는 예외**. 임시 순서: `color-blue-600` · `color-cyan-500` · `color-violet-500` · `color-amber-400` · `color-emerald-500` · `color-rose-400`(charts v1.0 확정 전).
- 축 · 격자선은 `divider-neutral-*`, 축 글자 12px `text-body-subtle`(`text-2xs`).
- 증감을 나타내는 차트 색은 increase(빨강) · decrease(파랑) 규칙과 같게.
- 차트에 표를 붙일 때는 [표](09-tables.md)의 "차트 아래 표" 규칙.
- 차트 카드 최소 높이: 작은 차트 240, 큰 차트 320.
