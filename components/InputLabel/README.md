# InputLabel

입력 레이블(피그마 Input Label sm · xs). 보통 FormField 안에서 자동으로 쓰이고, 직접 쓸 때는 필터 바 · 표 위 조건처럼 FormField 없이 레이블만 필요할 때.

**Props** — `size` xs 14(기본)|sm 15 · `color` gray(`text-body-main`)|white(`text-inverse-heading-main`) · `required` · `optional` · `tooltip` · `width`(90 · 120 · 180 · 210 고정 폭 또는 auto) · `htmlFor`.
- 글자 medium. 입력창 md · xl 옆은 xs, 2xl 옆은 sm.
