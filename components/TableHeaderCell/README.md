# TableHeaderCell

표 머리 셀(피그마 Header/Header Text · Header Checkbox · Header Empty). 표 안에서는 Table `columns`로 그려지고, 이 카드는 모든 변형을 낱개로 보여준다(`TableCell header`).
- 여백 8/12 · 높이 36, 판 기본 `table-header-subtle`(회색) + 글자 `text-sm` medium `text-body-main`. 흰 판(`table-header-main`)이면 글자 `text-body-subtle`. 아이콘 16 · 도움말(사이 6).
- 고정(Fixed): 아래(세로 스크롤, 머리 고정) · 오른쪽(가로 스크롤, 열 고정) 경계에 12 그림자 `table-fixed-overlay`.
- Checkbox: 폭 40, Checkbox xs(전체 · 일부 선택). Empty: 폭 40 · 높이 32 빈 칸.
