# PhoneVerification

본인인증(휴대폰 번호 → 인증번호) 입력 묶음. **인증번호 요청은 항상 이 흐름으로 만든다**(입력창 안 글자 버튼으로 만들지 않는다).

**Props** — `type` 1|2 · `size` md|xl(기본)|2xl · `title`("본인인증") · `phoneLabel`("휴대폰번호") · `codeLabel`("인증번호") · `duration`(초, 기본 180) · `codeLength`(기본 6) · `phone` · `code` · `requested` · `onRequest(phone)` · `onVerify(code)`.

**흐름**
1. 처음: 휴대폰번호 입력 + **인증 요청**(Primary soft, 항상 눌러 보이는 상태 — 번호가 비어 있으면 요청하지 않음)
2. 요청 후: 버튼이 **재요청**(Neutral soft — Type 1은 "인증번호 재요청", Type 2는 "재요청")으로 바뀌고, 아래에 **인증번호** 입력 + 남은 시간(입력창 오른쪽, `text-primary-main`, 03:00부터 1초씩) + **인증 완료**(Primary soft, 인증번호가 비어 있으면 동작하지 않음)가 나타난다.
3. 시간이 지나면 입력창 오류 + "인증 시간이 지났어요. 인증번호를 다시 요청해 주세요." / 완료하면 도움말 "인증이 완료되었어요."

**Type**
- **Type 1** — 버튼이 입력 **아래 꽉 찬 폭**(사이 8). 모바일 · 좁은 폼.
- **Type 2** — 버튼이 입력 **옆**(사이 8, 입력창과 같은 높이). 넓은 폼. 옆 버튼은 **고정 너비**(md 88 · xl 100 · 2xl 112)라 휴대폰번호 · 인증번호 두 줄의 입력창과 버튼 끝선이 맞는다.
- 묶음 사이(휴대폰번호 ~ 인증번호) 24, 레이블은 FormField(InputLabel xs).
- **폭은 놓인 영역을 꽉 채운다**(폼 칸 · 콘텐츠 영역 폭을 따름, `width`로 직접 지정 가능). 폭을 영역이 정하므로 남은 시간 · 버튼 글자 · 오류 문구가 바뀌어도 입력창이 들썩이지 않는다. 회원가입 · 로그인 폼은 보통 폼 폭(모바일 화면 폭 − 40, PC 폼 360~480)을 따른다.
