# TableTextCell

글자 셀(피그마 Cell/Text/Table Text · Table Contents). Type text · number · trend · rank × Style data · title × Align.
- data: `text-sm` normal `text-body-main`. title: 보조 글 `text-sm` + 제목 `text-md` **semibold** heading(TableTitle).
- number: 숫자(tabular) + 증감(TableNumber · ChangeBadge). trend: 증감만. rank: **1~3위 메달 아이콘**(피그마 circle/1st · 2nd · 3rd, 20), 4위부터 숫자.
- 옵션: 왼쪽 아이콘 16~18 · 배지 · 설명. Table Contents: 여러 줄 글, 여백 4/12.
