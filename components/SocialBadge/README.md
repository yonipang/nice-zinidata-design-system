# SocialBadge

소셜 로그인 · 가입 경로 표시(피그마 Social Badge · Mini Social Badge).

**Props** — `brand` kakao|naver|google · `mini` · `size`(로고 크기, 기본 20).
- 로고는 각 회사 규정 색 그대로(토큰 예외 — 브랜드 자산).
- **mini**: 18 네모 · 모서리 4 · 로고 10 · 옅은 테두리 `border-neutral-main`. 판 색: 카카오 노랑 · 네이버 초록(로고 흰색) · 구글 흰색. 프로필 이름 옆에 붙여 가입 경로를 보여줄 때.
