# TextCard

숫자 대신 **한 줄 결론 · 이름**을 보여주는 카드(피그마 Text Card). 판 · 제목 묶음은 StatisticCard와 같다.

**Props** — `size` lg|sm · `variant` card|ghost · `icon` · `title` · `badge` · `tooltip` · `description` · `rightIcon` · `body` · `footer` · `action`(Text Button) · `onAction`.
- 본문 `text-base` **semibold** `text-heading-main`(위아래 4).
- 아래 줄: 보조 글 `text-sm` medium `text-body-subtle` + 오른쪽 Text Button 3xs neutral-subtle(chevron-right).
